
# SmartSpend 
Sistema web desenvolvido com o objetivo de auxiliar no controle financeiro pessoal, permitindo que os usuários organizem suas receitas e 
despesas em um único lugar de forma simples, rápida e intuitiva.

Este projeto foi desenvolvido como trabalho acadêmico por uma equipe de **4 integrantes**, colocando em prática autenticação de usuários, integração com banco de dados e gerenciamento financeiro.

## Objetivo

O Controle Orçamentário surgiu da necessidade de facilitar o acompanhamento das finanças pessoais.

Muitas pessoas possuem dificuldades para visualizar seus gastos e receitas de maneira organizada, o que pode resultar em um planejamento financeiro ineficiente. Pensando nisso, o sistema foi desenvolvido para centralizar informações financeiras em uma única plataforma, proporcionando maior controle e clareza sobre a situação financeira do usuário.
